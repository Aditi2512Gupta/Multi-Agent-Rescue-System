# 🚁 Multi-Agent Rescue System

An AI-powered disaster response simulation system built using HTML, CSS, and JavaScript.  
This project demonstrates intelligent search, human classification, pathfinding, and rescue operations in a disaster environment.

## 🌟 Features

- 🔍 Real-time grid scanning simulation
- 🤖 AI-based human classification system
- 🚁 Drone rescue operation animation
- 🧭 A* Pathfinding Algorithm
- 🏥 Priority-based rescue system
- 📊 Live statistics dashboard
- 🎮 Interactive disaster-response simulator
- 💻 Fully responsive modern UI

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Tailwind CSS

---

## 🧠 System Functionality

The system simulates:
- Disaster environment scanning
- Human detection using virtual sensors
- Classification into rescue priority levels:
  - H1 → Critical
  - H2 → Urgent
  - H3 → Medical
- Intelligent rescue path planning using A* Algorithm
